## 已知脚本输出文件名冲突

本轮先执行 `--only a2`，生成默认文件 `a2_a3_20261106_offline_audit.json`；再执行 `--only a3` 时计算完成但因相同默认 JSON 名称发生 `FileExistsError`，不是诊断算法失败。**远程最新脚本已具有按 `--only` 参数使用 `_a2.json`、`_a3.json` 和 `_all.json` 分离输出的逻辑。** 在 Ubuntu `git pull --ff-only` 后使用新版本运行，或用 `--out` 显式指定新的路径。不得删除/覆盖旧 JSON。
